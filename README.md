# Roam · 开口去旅行

个人旅游与生活口语练习网站，v0.2.0。保留30天学习周期、10–30秒分段录音、原始录音档案、重练版本与周复盘。

## v0.2：不再需要OpenAI

本版使用阿里云百炼北京地域转写原音，Kimi分析用户确认后的文字。两项分别授权、分别显示配置状态。原始录音保留在原Supabase私有空间；不需要重建数据库或执行迁移。

请阅读 [SETUP.md](SETUP.md) 配置。不要把真实密钥或录音提交到这个公开仓库。仓库中的“开始使用.html”是v0.1历史指南，OpenAI部分不再适用。

## 开发与检查

需要Node.js 22。无运行时第三方依赖。

```sh
npm run build
npm test
npm run dev
```

48项本地测试通过；供应商及数据库网络响应使用模拟数据，不等于真实API调用或手机验收通过。测试范围见 [TESTING.md](TESTING.md)。

## 使用边界

本版只评核对后的文字，不评发音、口音、停顿、正式等级，也不保证锁屏连续对练。参考分只针对当前回答。先用非隐私短录音测试完整流程，定期导出含音频的备份。
