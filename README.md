# Roam · 开口去旅行

旅游与日常生活英语口语的个人试用版，v0.1.0。每轮回答独立保存；30天为一个可重复学习周期。

**第一次使用请阅读 [SETUP.md](SETUP.md)。也可以双击项目包中的 `开始使用.html`。**

## 当前交付状态

这是已编写并通过本地构建、逻辑测试与隔离页面测试的源码，不是已经在你的账号中发布的在线服务。
GitHub、Vercel、Supabase 的实际部署和授权，以及手机麦克风、真实云端、OpenAI调用，必须由账号持有人完成配置后验证。

- 无配置时：30天旅游／生活课程、系统语音朗读、短回合录音、本机回放与重练、按周期的记录统计及手动周复盘、备份导出恢复。
- 配置Supabase并执行SQL后：邮箱密码登录、私有云端录音、跨设备同步、删除与重试。
- 额外配置OpenAI API和允许邮箱后：真实转写 → 用户核对 → 表达反馈 → AI上下文追问。
- 不包含：锁屏连续录音、后台连续对话、离线AI、发音评测、正式等级测评、支付会员、商务课程。

## 技术组成

- 前端：原生JavaScript模块、HTML、CSS，无第三方运行时包。
- 音频：MediaRecorder，每次回答一个独立文件；中途草稿和结束后的正式录音保存在IndexedDB。
- 服务端：Vercel Node.js Functions。OpenAI密钥从服务端环境变量读取，不发送到网页。
- 云端：Supabase Auth、Postgres、私有Storage。所有读写以当前学习用户的JWT进行，不使用service-role或secret key。
- 逐段上传由客户端直传私有Storage，避免把原音频经过Vercel请求体。
- PWA：主屏幕图标、基础页面缓存。缓存不等于永久备份，不保证后台运行。

## 开发者本地运行

需要Node.js 22；没有必须安装的运行依赖。

```sh
npm run dev
# 浏览器打开 http://localhost:4173
```

需要本地调用云端时，把`.env.example`复制为`.env.local`，在自己电脑填写（绝不提交）：

```sh
node --env-file=.env.local scripts/dev.mjs
```

构建与检查：

```sh
npm run build
npm test
```

Vercel：Framework Preset 为 Other／无框架，Build Command 为 `npm run build`，Output Directory 为 `dist`。
`vercel.json`已提供对应设置。不要把源码项目的根目录改为`src`、`public`或`dist`。

## 维护原则

先备份 → 修改源码 → 构建与测试 → 预览部署 → 用手机验收 → 再发布正式版。
新代码不能直接删除已有录音、改为公开Storage、开放注册或把私密配置写进前端。
导出文件含私人声音和转写，请勿上传公开仓库。
课程周期、录音ID、模型名、评分规则版本均保留；旧题重练不当作整体水平提升。

## 评分边界

v0.1只依据用户确认的转写，评“任务完成／表达清晰／语法用词”，各0–5分，均权换算内部参考分。
这不是发音评分、流利度音频测评、雅思分数或CEFR等级。文本证据不足时不给分。
记录时长包括思考停顿，不等于净发言时长。周复盘是实际数据汇总＋自评，不冒充经过独立验证的学习效果。
AI输出可能有误；原话引用、分值和输出结构会检查，但仍需回听与人工判断。

## 隐私与迁移

网页不要求提交真实订单、证件、健康或客户数据。练习情境使用虚构姓名、预订号等。
第三方服务：配置的Supabase项目；仅在用户同意并主动请求时调用OpenAI。
删除会请求删除自己项目里的音频与关联记录；离线时保持待删除标记。AI服务方日志及数据处理遵循其自身政策，网页不能撤回已处理请求。
认证会话只保存在此浏览器，不进入备份。退出不自动删除本机音频；共享设备需额外清除。
代码、云端账号、数据应始终由你持有。将来原生App可复用后台及课程，但前端音频、权限、后台执行与上架需要另行开发。
